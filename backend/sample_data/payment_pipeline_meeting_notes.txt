1. Executive Summary & Objective:
Modernize legacy daily batch settlement into a near-real-time streaming pipeline. The current system relies on nightly FTP file dumps that regularly fail during peak volumes and require up to 4 hours of manual reconciliation. The new pipeline must ingest payment authorization and settlement records across 14 European and North American payment schemes with zero data loss.

2. In-Scope Deliverables:
- Real-time payment ingestion API gateway supporting REST/JSON and ISO 20022 compliant message payloads.
- Automated payload schema validation engine against PCI-DSS and financial data formats.
- High-throughput Kafka messaging tier with idempotent deduplication.
- Dead Letter Queue (DLQ) with self-service retry console for operations analysts.
- Real-time audit trail and transaction reconciliation export to Snowflake warehouse.

3. Out-of-Scope:
- Direct consumer mobile checkout UI (managed by Front-End Digital Apps team).
- Legacy mainframe ledger settlement (scheduled for complete sunset in Q3 2027).
- Cryptocurrency or alternative token payment rails (deferred to Phase 2).

4. Key Performance Indicators & SLAs:
- Processing latency under 1,500 milliseconds for 99% of payment authorizations.
- 99.99% system availability during operating market hours.
- Throughput capacity up to 5,000 transactions per second during Black Friday peak load.

5. Key Constraints & Acronyms:
- PCI-DSS: Payment Card Industry Data Security Standard
- ISO: International Organization for Standardization
- DLQ: Dead Letter Queue
- IdP: Identity Provider
- TPS: Transactions Per Second
- MTTR: Mean Time to Resolution
